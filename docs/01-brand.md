# Thyssen Digital - Brand Foundations

## Décisions validées

- Nom de marque : THYSSEN DIGITAL.
- Positionnement : studio digital premium.
- Signature officielle : Concevoir. Développer. Performer.
- Univers visuel : Luxe Tech.
- Direction : sobre, élégante, technologique et intemporelle.
- Palette : environ 95 % noir, gris et blanc.
- Accents : bleu et cyan, avec un violet très discret.
- Interdits : gaming, cyberpunk, surcharge visuelle, effets RGB.
- Le fait que le fondateur travaille seul n'est pas mis en avant.
- Objectif polyvalent : clients premium, applications web, missions freelance et vitrine professionnelle.

## Monogramme TD

Sprint 4 introduit un monogramme vectoriel original `T` + `D`.

- Structure principale : un `T` géométrique compact.
- Intégration du `D` : barre supérieure commune, courbe extérieure nette et espace négatif intérieur.
- Usage prioritaire : symbole seul à petite taille, puis version horizontale avec `THYSSEN DIGITAL`.
- La signature officielle reste `Concevoir. Développer. Performer.` et ne doit pas surcharger la navbar.

Le symbole doit rester identique entre les variantes. Seule la couleur change.

## Variantes

- `td-mark.svg` : version monochrome utilisant `currentColor`.
- `td-mark-white.svg` : version blanche.
- `td-mark-black.svg` : version noire.
- `td-mark-accent.svg` : version web avec accent bleu, cyan et violet discret.
- `thyssen-digital-horizontal.svg` : version horizontale web.
- `favicon.svg` : favicon basé sur le même monogramme.

## Règles d'usage

- Taille minimale recommandée : `16 x 16 px` pour le symbole seul.
- Zone de protection : conserver au moins un quart de la largeur du symbole autour du logo.
- Utiliser les versions monochromes lorsque le contexte exige une lisibilité stricte.
- Utiliser la version accent uniquement sur les interfaces web Thyssen Digital.
- Ne pas ajouter d'ombre, glow, effet 3D, contour décoratif ou rotation.
- Ne pas modifier les proportions, la courbe extérieure ou l'espace négatif du `D`.
